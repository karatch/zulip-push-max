# Zulip to Maks Secure Push Gateway

Высокопроизводительный асинхронный интеграционный шлюз (микросервис) на Python для мгновенной пересылки корпоративных push-уведомлений из чат-пространства **Zulip** в персональные чаты сотрудников в мессенджере **«Макс» (МКС)**.

---

## Ключевые особенности и архитектура

* **Легковесный движок (Без сторонних фреймворков):** Логика работы бота полностью переведена на нативный асинхронный Long Polling (`/events/get`) через библиотеку `aiohttp` [3.2]. Приложение избавлено от тяжелых зависимостей (вроде `aiogram`), что минимизирует потребление RAM и ускоряет сборку.
* **Защищенная двухфакторная аутентификация (2FA / OTP):** Исключен риск шпионажа и брутфорса чужих аккаунтов. Привязка профиля происходит через ввод корпоративного email. Шлюз сверяет адрес со списком разрешенных доменов, находит сотрудника на сервере Zulip по реальному полю `delivery_email` через метод `.get_users()` и отправляет ему случайный 4-значный одноразовый пароль (OTP) в личные сообщения внутри Zulip [3.2].
* **In-Memory FSM (Конечный автомат):** Управление шагами авторизации пользователя (`WAIT_EMAIL` -> `WAIT_OTP`) реализовано на базе потокобезопасного словаря в оперативной памяти. Данные сессий изолированы, не требуют дисковых ресурсов и мгновенно очищаются при завершении.
* **Нативный Markdown-транслятор:** Мессенджер «Макс» изначально спроектирован на базе синтаксиса Markdown. Шлюз транслирует сообщения из Zulip (`content_raw`) напрямую, сохраняя исходную структуру текста, жирный шрифт, списки и блоки кода без необходимости ресурсоемкого HTML-экранирования.
* **Deep Linking (Переход к сообщению в 1 клик):** Все входящие пуши содержат прямую экранированную кликабельную ссылку (`urllib.parse.quote`). При тапе по ссылке пользователь мгновенно перемещается к нужному треду или сообщению в интерфейсе Zulip.
* **Контроль трафика (Throttling) и Fail-Fast:** Использование асинхронных семафоров (`asyncio.Semaphore(20)`) ограничивает количество одновременных запросов к API мессенджера «Макс», защищая шлюз от блокировок по Rate Limit. Сетевые таймауты жестко ограничены отметкой в 3 секунды.
* **Мгновенный Graceful Shutdown:** Использование асинхронных событий (`asyncio.Event`), запуск слушателя Zulip в выделенном пуле демон-потоков (`ThreadPoolExecutor`) и системное прерывание `os._exit(0)` гарантируют, что приложение мгновенно завершает работу с первого клика с успешным `Exit code 0` [3.2].

## Инструкция для сотрудников: Подключение уведомлений

Чтобы начать получать мгновенные пуши в мессенджер «Макс» без необходимости держать открытым тяжелое мобильное приложение Zulip, выполните 3 простых шага:

### Шаг 1. Запустите бота
1. Найдите корпоративного бота в мессенджере «Макс» и отправьте ему текстовую команду **Старт** или `/start`.

### Шаг 2. Укажите корпоративный email
1. Введите команду `/bind` (или напишите слово `привязать`).
2. Введите вашу рабочую почту (например, `alex@company.com`).
3. Бот автоматически проверит ваш адрес в белом списке организации и сгенерирует секретный код верификации.

### Шаг 3. Введите код подтверждения (OTP)
1. Откройте приложение или веб-версию **Zulip**.
2. Перейдите во вкладку **Личные сообщения (Direct messages)**. Найдите чат от имени нашего корпоративного бота — там будет находиться 4-значный цифровой код.
3. Скопируйте этот код, вернитесь в мессенджер «Макс» и отправьте его боту.

**Успешно!** Интеграция активирована. Теперь новые сообщения из всех публичных стримов Zulip, в которых вы состоите, будут мгновенно дублироваться вам в чат с ботом.

## Инструкция по развертыванию для Администратора

### 1. Подготовка конфигурационных файлов
В корневой папке приложения должны находиться два файла конфигурации.

Создайте файл окружения **`.env`**:
```env
# Токен вашего бота в мессенджере Макс
MAKS_BOT_TOKEN=Bot1234567890.abcdefghijklmnopqrstuvwxyz

# Корпоративный URL-адрес Bot API вашего сервера Макс
MAKS_API_URL=https://company.com

# Разрешенные корпоративные домены для регистрации (без @, через запятую)
ALLOWED_COMPANY_DOMAINS=company.com,://company.com
```
*Убедитесь, что файл `.env` добавлен в `.gitignore` вашего репозитория!*

Положите рядом стандартный файл авторизации **`zuliprc`** вашего Generic-бота с правами Администратора организации Zulip:
```ini
[api]
site = https://company.com
email = push-bot-bot@://company.com
key = abcdefghijklmnopqrstuvwxyz123456
```

### 2. Установка зависимостей и запуск
1. Установите необходимые библиотеки:
   ```bash
   pip install -r requirements.txt
   ```
2. Запустите шлюз:
   ```bash
   python3 run.py
   ```

## Настройка фоновой службы Linux (Systemd)

Для обеспечения непрерывной работы 24/7 настройте шлюз как системную службу от имени безопасного изолированного пользователя.

1. Создайте системного пользователя и передайте ему права на папку проекта:
   ```bash
   sudo useradd -r -s /bin/false zulip-push
   sudo chown -R zulip-push:zulip-push /opt/zulip-maks
   ```

2. Создайте файл службы `/etc/systemd/system/zulip-maks-bridge.service`:
   ```ini
   [Unit]
   Description=Zulip to Maks Secure Push Gateway
   After=network.target

   [Service]
   Type=simple
   User=zulip-push
   Group=zulip-push
   WorkingDirectory=/opt/zulip-maks
   ExecStart=/usr/bin/python3 /opt/zulip-maks/run.py
   Restart=always
   RestartSec=10
   StandardOutput=syslog
   StandardError=syslog
   SyslogIdentifier=zulip-maks-bridge

   [Install]
   WantedBy=multi-user.target
   ```

3. Активируйте и запустите службу:
   ```bash
   sudo systemctl daemon-reload
   sudo systemctl enable zulip-maks-bridge.service
   sudo systemctl start zulip-maks-bridge.service
   ```
